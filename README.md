# Creator Personal Website 🎬

Live Link: https://creator-website.vercel.app/

A modern, high-quality personal website for content creators built with Next.js, React, Tailwind CSS, and Framer Motion.

## ✨ Features

- **Modern Dark Theme** - Sleek dark design with gradient accents
- **Glassmorphism UI** - Beautiful glass-effect cards and components
- **Advanced GSAP Animations** - Professional scroll-triggered and interactive animations
- **Smooth Animations** - Powered by Framer Motion + GSAP for buttery smooth interactions
- **3D Transform Effects** - Cards with 3D rotation and depth
- **Scroll Animations** - Elements animate as you scroll through the page
- **Custom Cursor** - Gradient cursor that follows mouse movement
- **Page Transitions** - Smooth page load animations
- **Fully Responsive** - Perfect on mobile, tablet, and desktop
- **Performance Optimized** - Built with Next.js 15 for optimal performance
- **Accessible** - WCAG compliant with proper ARIA labels

## 🎨 Design Highlights

- Gradient text effects (purple → pink → blue)
- Soft shadows and glow effects
- Hover micro-interactions
- Smooth scroll behavior
- Floating animations with GSAP
- 3D card rotations and flips
- Scroll-triggered animations
- Stagger effects for lists
- Elastic and bounce easing
- Continuous pulsing and floating elements
- Category filtering with smooth transitions
- Custom animated cursor
- Page load transitions

## 📦 Tech Stack

- **Framework:** Next.js 15 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion + GSAP (GreenSock)
- **Icons:** Lucide React
- **Font:** Inter (Google Fonts)

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ installed
- npm or yarn package manager

### Installation

1. Navigate to the project directory:
```bash
cd creator-website
```

2. Install dependencies:
```bash
npm install
```

3. Run the development server:
```bash
npm run dev
```

## 📱 Responsive Breakpoints

- Mobile: < 768px
- Tablet: 768px - 1024px
- Desktop: > 1024px
